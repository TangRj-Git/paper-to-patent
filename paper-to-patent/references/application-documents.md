# Application Documents

Use this file when drafting the application-facing materials that map to the five-document set.

## Outputs

Create these files under `draft/application/`:

1. `请求书信息表.md` from `assets/templates/request-form-info.md`
2. `权利要求书.md` from `assets/templates/claims.md`
3. `说明书.md` from `assets/templates/specification.md`
4. `说明书摘要.md` from `assets/templates/abstract.md`
5. `说明书附图清单.md` from `assets/templates/drawings-list.md`

If drawings are used, also prepare `摘要附图说明.md` or identify the recommended abstract drawing.

## Mapping To 五书

| 五书模块 | Local artifact | Notes |
|---|---|---|
| 请求书 | `请求书信息表.md` | Information checklist only; not a replacement for official electronic filing forms |
| 权利要求书 | `权利要求书.md` | Defines protection scope |
| 说明书 | `说明书.md` | Supports every claim and explains embodiments |
| 说明书摘要 | `说明书摘要.md` | Brief technical summary; avoid unsupported effects |
| 说明书附图 | `说明书附图清单.md` plus `figures/` | Patent drawing list and source files |

## Drafting Order

1. Draft claims first.
2. Draft specification to support every claim term.
3. Draft abstract from the confirmed specification.
4. Draft drawings list after figure names and figure purpose are stable.
5. Prepare request-form information checklist from user-provided bibliographic data.

## Missing Request-Form Information

If inventor, applicant, address, priority, contact, or filing entity information is missing, leave it as "待用户提供". Do not invent bibliographic data.
