# Current CNIPA-Oriented Drafting Notes

Use this file when current official patent requirements, algorithm/AI examination rules, or legal-risk language matters. Verify official sources again if the user needs submission-ready legal guidance.

## Core Drafting Constraints

- The specification should describe the invention clearly and completely enough for a person skilled in the art to implement it.
- Claims should be based on the specification and clearly define the requested protection scope.
- Algorithm, AI, or data-processing features should be connected to a concrete technical field, technical problem, technical means, and technical effect.
- Do not present pure mathematical rules, business rules, management methods, or abstract algorithms as a technical solution without a concrete technical application.

## AI/Data-Specific Cautions

For machine learning, big data, or model patents, check:

- source and nature of input data;
- whether data acquisition and processing are lawful and appropriate;
- whether the model produces a technical output in a technical scenario;
- whether the method improves a technical process, technical system, or technical effect;
- whether the draft avoids unsupported social, legal, or medical claims.

## Currency Note

Do not rely on this local note as a current legal source. Patent examination guidelines and filing rules can change.
