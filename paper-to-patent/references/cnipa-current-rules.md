# Current CNIPA-Oriented Drafting Notes

Use this file when current official patent requirements, algorithm/AI examination rules, or legal-risk language matters.

## Boundary

This local note is not a current legal source. If the user needs submission-ready legal guidance, exact form requirements, official fee/form rules, or current AI/data examination policy, verify the latest official CNIPA sources or recommend patent-agent review.

## Core Drafting Constraints

- The specification should describe the invention clearly and completely enough for a person skilled in the art to implement it.
- Claims should be based on the specification and clearly define the requested protection scope.
- Algorithm, AI, or data-processing features should be connected to a concrete technical field, technical problem, technical means, and technical effect.
- Avoid presenting pure mathematical rules, business rules, management rules, or abstract algorithms as patentable technical solutions without a concrete technical application.

## AI/Data-Specific Cautions

For machine learning, big data, model, optimization, or scheduling patents, check:

- source and nature of input data;
- whether the model produces a technical output in a technical scenario;
- whether the method improves a technical process, technical system, or technical effect;
- whether the claimed feature is more than a generic "use AI/model" statement;
- whether unsupported social, legal, medical, or business effects are avoided.

## Template-Derived Format Notes

The local Word templates and published patent samples show these stable drafting conventions:

- claims are numbered with Arabic numerals;
- the specification uses 技术领域、背景技术、发明内容、附图说明、具体实施方式;
- the abstract should state name, field, problem, solution points, and use, and should stay within 300 Chinese characters;
- specification drawings and abstract drawing are separate five-document materials before Word assembly;
- the Markdown drafts should mark figure positions only, while real drawing files should be kept as separate handoff files.
