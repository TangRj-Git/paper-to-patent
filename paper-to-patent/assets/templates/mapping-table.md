# 论文-专利内容映射表

| 论文内容 | 专利对应位置 | 是否可直接使用 | 是否需要改写 | 依据位置 | 注意事项 |
|---|---|---:|---:|---|---|
| 研究背景 | 背景技术 | 是 | 是 |  | 避免写成文献综述 |

| 模型/系统结构 | 权利要求、具体实施方式、附图 | 是 | 是 |  | 模块名全文统一 |

| 实验结果 | 有益效果 | 谨慎 | 是 |  | 不写具体排名和表格 |
| 消融/对比实验 | 通常不写 | 否 | 否 |  | 除非能支撑技术效果 |
| 未来工作 | 不写 | 否 | 否 |  | 不能写成已实现功能 |
